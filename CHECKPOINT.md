# CargoX prototype checkpoint

Checkpoint: `v0.1.0-prototype` · 29 October 2026.

This preserves the interactive eighty-car demonstration before adding autonomous bargaining or credit payments. It includes the physical driving engine, evolving passage options, incoming requests, requests to release the head of a queue, translucent future previews, concurrent compatible passage agreements, and observed delivery/fault handling. The shared-lane C66/C28 repair is included.

Cars use conventional driving algorithms. The possible exchanges are discovered by programmed rules and approximate forecasts. Selecting an outgoing request directly installs a feasible passage agreement; the other car does not independently accept or price it. The displayed time changes are conditional local estimates, not proven destination savings. This checkpoint makes no claim of learned cooperation or improved traffic efficiency.

## Return to this checkpoint

For a separate copy that leaves ongoing work alone:

```sh
git clone --branch v0.1.0-prototype https://github.com/AhHamedi/CargoX.git CargoX-checkpoint
cd CargoX-checkpoint
uv sync --extra test
./start
```

To work forward from that copy, create a branch with `git switch -c my-experiment`.

## What is preserved

The repository contains source, interface, tests, road geometry and the required generated reference at `data/community/layout-traffic.json.gz`. Its SHA-256 is `65efe08774afefe5b7961e908bdb0e5b0d936a2cc70fd04da7b6d05821311a79`. The interactive drive uses its initial state, geometry and routes; later motion is generated by the physical engine. The file also retains the ordinary reference replay for the existing inspection views.

Local trained weights, Python environments, credentials, generated model responses, recordings and historical research archives are excluded from uploads. They remain on the original machine. Git restores the code and initial environment; it does not restore an unsaved browser position or a live process. Demonstration recordings remain under `data/community/demonstrations/` locally.
